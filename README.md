# 複丈歷史資料匯出工具

將複丈案件資料夾（如 `KC0391`）內的 D 系列檔案（界址點/参考點/補點/地籍線/宗地）轉換為
GeoPackage，輸出到相鄰 `QGIS\複丈歷史\` 資料夾，並自動更新 QGZ 專案檔的「複丈歷史」圖層群組。

單機執行、免安裝，直接雙擊 `dist\複丈歷史資料匯出工具.exe` 即可使用，不需要另外安裝 Python 或 QGIS。

## 使用方式

1. 執行 `複丈歷史資料匯出工具.exe`
2. 「選擇資料夾…」選擇案件資料夾（例如 `KC0391`，資料夾內需有 `KC0391.D14` 等檔案）
   - 程式會自動偵測同層的 `QGIS` 資料夾與其中的 `.qgz` 專案檔、`複丈歷史` 輸出資料夾
   - 若找不到 QGZ 專案檔，可用「另選檔案…」手動指定，或留空只輸出 GPKG
3. 輸入複丈日期（預設今天，可修改，用於檔名與 QGIS 群組命名）
4. 選擇輸出範圍：
   - **全部地號**：輸出案件內所有界址點/地籍線/宗地
   - **指定地號**：於搜尋欄輸入關鍵字篩選清單，再從清單中點選地號（可用 Ctrl/Shift 複選多筆），
     也可用「全選」「清除」按鈕批次操作；若尚未選擇任何地號就按「開始輸出」，會跳出提示視窗並中止，不會產生任何檔案
   - **補點／参考點／参考線**：這三種不跟地號綁定關聯性判斷，用獨立的核取方塊控制「全部輸出」或
     「完全不輸出」，預設勾選（全部輸出）。也就是說即使指定單一地號，只要勾了這個選項，
     案件內全部的補點／参考點／参考線還是會整批輸出，不會被地號篩選掉。
5. 按「開始輸出」，確認後即會：
   - 在 `QGIS\複丈歷史\` 產生 `{案號}_{日期}.gpkg`
   - 備份原 QGZ 專案檔為 `.bak`，並將新圖層掛入「複丈歷史」>「{案號} ({日期})」群組

## 自動更新

程式每次啟動時會在背景檢查 [GitHub Releases](https://github.com/chenweihanfool/kc-survey-history-tool/releases)
是否有新版本。若發現更新：下載新版 exe → 顯示「即將重新啟動」→ 自動以新版覆蓋目前執行檔並重啟，全程不需手動確認。

- 檢查失敗（沒有網路等）會安靜略過，照常開啟目前版本，不會卡住。
- 僅打包為 exe 執行時才會自我更新；以原始碼 `python main.py` 執行只會記錄有新版可用。
- 發布新版：在 [version.py](version.py) 調整 `APP_VERSION`，打包後以該版本號建立 GitHub Release
  並附上 exe 檔案即可（release 的 `.exe` 附件檔名不影響更新邏輯，只要副檔名是 `.exe` 且是該 release 下第一個即可）。

## 資料夾結構假設

```
<專案根目錄>/
  KC0391/              <- 案件資料夾（.D14/.D21/.D2B 等檔案），未來可能是 KXXXXX
  QGIS/
    kc_ctl.qgz         <- QGIS 專案檔
    複丈歷史/           <- 輸出的 GPKG 存放於此
```

程式假設案件資料夾與 `QGIS` 資料夾是同一層的兄弟目錄。

## 原始碼／重新打包

原始碼在 `app/` 目錄，皆為標準函式庫（無需安裝套件即可執行 `python main.py`）。
若要重新打包成 exe：

```bash
pip install pyinstaller
cd app
python -m PyInstaller --onefile --windowed --name "複丈歷史資料匯出工具" main.py
```

## 資料來源與判讀邏輯

- 座標系統固定為 TWD97 / TM2 zone 121（EPSG:3826），D 系列檔案座標本身已是此系統，不再轉換。
- 點位優先採用 D2C（若有資料），否則使用 D14。
- 地籍線優先採用 D2D（若有資料），否則使用 D21。
- 宗地邊界優先採用 D2B（若有資料），否則使用 D13。
- 宗地面積／地目屬性取自 D11（依段別+母號+子號比對）。
- 補點（D20）／参考點（D14 小數編碼）／参考線（D29）不做地號關聯篩選，由 GUI 的核取方塊
  獨立控制全部輸出或完全不輸出（見上方使用方式第 4 點）。

本工具參考 [ka-tool](https://github.com/chenweihanfool/ka-tool) 專案的複丈資料處理邏輯，
改寫為可直接讀寫本機檔案系統的單機 Python 程式（原專案為純前端 HTML，僅能手動下載檔案）。
